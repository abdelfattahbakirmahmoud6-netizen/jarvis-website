# JARVIS Website

موقع محلي مستقل يقدّم مشروع JARVIS كمساعد Windows بالصوت والكتابة. الموقع لا يعتمد على Manus أو قاعدة بيانات، ويمكن تشغيله مباشرة بملفات HTML/CSS/JavaScript.

## التشغيل

```bash
cd jarvis-website
python3 -m http.server 4175 --bind 0.0.0.0
```

ثم افتح `http://localhost:4175`.

## المحتوى

- صفحة تعريفية ثنائية اللغة عربي/إنجليزي.
- عرض للمزايا والأوامر وحدود الأمان.
- Console تفاعلية تجريبية داخل الصفحة.
- رابط تحميل مشروع JARVIS الأصلي.
- تصميم متجاوب للكمبيوتر والموبايل.

## التخصيص

عدّل النصوص داخل `index.html`، والألوان والتخطيط داخل `styles.css`، وسلوك العرض التفاعلي داخل `app.js`.
